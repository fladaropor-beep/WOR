# ShoeShop — информационная система магазина обуви

Учебный вариант проекта на тему интернет-магазина обуви. Структура сохранена: папка `db` содержит схему, запросы и CSV-данные, папка `docs` — паспорт, отчёт, таблицы, сценарии и диаграммы.

Основные отличия варианта: новое название проекта, обновлённые формулировки в текстовых материалах и собственное оформление описания проекта. Перед сдачей проверьте, что имя команды и титульные листы документов соответствуют вашим данным.
